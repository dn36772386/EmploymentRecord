# Teams チャットタイトルにIDが入らないときの確認ポイント

このガイドは、Power Automate の「グループチャットを作成する（Create a group chat）」でチャットタイトルにIDが入らない場合に、素早く原因を切り分けるためのチェックリストです。

## まず前提を確認
- 1:1 チャットにはタイトルの概念がありません。タイトルを設定できるのは「グループチャット」のみです。
- 使用しているコネクタが「Microsoft Teams (標準)」であることを確認してください（プレビュー/非推奨コネクタは仕様が異なることがあります）。

## 画面での確認項目（Power Automate）
1. 対象アクションが「グループチャットを作成する」になっているか（1:1 だとタイトルは無効）
2. チャットの種類（Chat type）が `Group` になっているか
3. チャットタイトル/subject フィールドに、ID が入る式または動的コンテンツを設定しているか
   - 例（SharePoint トリガのIDを使う場合）:
     ```
     承認依頼 (ID: @{triggerOutputs()?['body/ID']})
     ```
   - もしくは動的コンテンツで「ID」を選択して挿入
4. フィールド名の大文字/小文字や内部名の誤りがないか
   - SharePoint の列名は `ID`（大文字）です。`Id` や `id` は別物です。
5. 文字列結合の式が壊れていないか
   - 例: `concat('承認依頼 (ID: ', triggerOutputs()?['body/ID'], ')')`
6. 先行アクションの出力を参照している場合、そのスコープ内にあり、スキップされていないか

## よくあるNGパターン
- 1:1 チャットアクションを使っている（タイトルは無視される）
- 動的コンテンツで `Id` を選んでしまっている（大小が違う）
- 複数トリガ/ブランチでコンテキストが違い、`triggerOutputs()` の `ID` が空
- HTML/リッチテキストの文字列をそのまま入れてTeams側でサニタイズされて欠落

## 検証のコツ
- 作成後のチャットを開き、実際のタイトルがどのようになっているか確認
- 一時的にタイトルを固定値（"TEST @{utcNow()}"）にして、式の問題かどうか切り分け
- 実行履歴でアクション入力（Inputs）の JSON を展開し、`subject` や `title` の解決後文字列を確認

## それでも解決しない場合
- フローを ZIP エクスポートし、JSON を検索して `subject`/`title` の値を直接確認
- コネクタの既知の制限・不具合の有無を確認（Microsoft 公式ドキュメント）
- 環境権限/ライセンスに問題がないか（アプリ許可、Teams へのアクセス）
